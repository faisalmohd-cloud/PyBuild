Terminal-native builder for Python projects.

                
PyBuild initializes, scaffolds, and packages small Python libraries or executables
                    without the ceremony. Optimized for Windows terminals with clean defaults and an interactive
                    shell.

                

                     1.0-windows
                    Lightweight CLI
                    Interactive shell
                

                

                    Download PyBuild
                    View on GitHub
                

                
Works best on Windows today. Linux/macOS support planned.

            

        


        

            

                
Why PyBuild

                
Ship quick project scaffolds, build executables, and keep the terminal flow.

            

            

                

                    

                        
                    

                    
Fast starts

                    
Initialize executable or library layouts with sensible defaults, optional Git setup, and
                        ready-to-run virtual environments.

                

                

                    

                        
                    

                    
Build & clean

                    
Build libraries or PyInstaller executables with one command. Use --clean to wipe stale artifacts
                        before packaging.

                

                

                    

                        
                    

                    
Interactive shell

                    
Drop into a minimal shell for quick file operations like ls, cd, mkdir, cp, mv, rm, and more.

                

                

                    

                        
                    

                    
Opinionated, not heavy

                    
Small binary, clear outputs, and roadmap toward templates, better help, and cross-platform
                        support.

                

            

        


        

            

                
Core commands

                
Minimal switches, predictable output. Copy-paste ready.

            

            

                

                    
Initialize a project

                    
                    
pybuild init . exe --git
pybuild init Projects lib --git
pybuild init MyTool exe

                

                

                    
Build and clean

                    
                    
pybuild build MyLibrary --clean
pybuild build MyExe
pybuild
